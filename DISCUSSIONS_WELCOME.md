## Добро пожаловать в PRO Edit

Здесь обсуждаем работу помощника редактора объявлений ТРК «Ритм».

### Куда писать

| Раздел | Для чего |
| --- | --- |
| **Q&A** | Вопросы по установке, горячим клавишам, холдерам, обновлению |
| **Ideas** | Предложения новых возможностей |
| **Announcements** | Официальные новости о версиях (пишут сопровождающие) |
| **Issues → Сообщить о проблеме** | Ошибки с шагами воспроизведения |

### Перед публикацией

1. Воспользуйтесь поиском — вопрос мог уже обсуждаться.
2. Укажите **версию PRO Edit** и **версию Windows**.
3. Для ошибок — пошаговое воспроизведение.

### Важно

Не публикуйте пароли, SSH-ключи, токены и персональные данные.

Скачать программу: корневая страница репозитория — файлы `PRO-Edit.rar` и `PRO-Edit.exe`.

Горячие клавиши по умолчанию: **Ctrl+/** — шаблоны, **Ctrl+E** — холдеры.
