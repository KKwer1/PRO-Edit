# PRO Edit

Официальные сборки помощника редактора объявлений **ТРК «Ритм»** (Radmir CRMP).

Этот репозиторий — только для скачивания программы, обновлений и обратной связи. Исходный код закрытый и здесь не публикуется.

## Скачать

| Файл | Назначение |
| --- | --- |
| [PRO-Edit.rar](./PRO-Edit.rar) | Архив для установки (exe + инструкция) |
| [PRO-Edit.exe](./PRO-Edit.exe) | Готовый файл для автообновления |
| [latest.json](./latest.json) | Версия, ссылка и контрольная сумма |

Текущая версия указана в `latest.json`.

**Системные требования:** Windows 10/11.

Программа без цифровой подписи. Windows SmartScreen может показать «защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае». Скачивайте только из этого репозитория.

## Возможности

- шаблоны объявлений и мастер холдеров;
- отдельные формулировки для велосипедов, скейтов и сноубордов;
- умный поиск: `велик`, `дц батка`, `продам кабан 10кк`;
- автозамена по пробелу;
- проверка по правилам П.Р.О. перед вставкой;
- интерфейс: русский, английский, армянский, узбекский.

## Горячие клавиши по умолчанию

- `Ctrl+/` — меню шаблонов  
- `Ctrl+E` — холдеры  
- `Esc` — закрыть / назад  

Сочетания можно сменить в настройках.
